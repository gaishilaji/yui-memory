开始从零学消化科。第一课不是背病名，是先看清"这条路"和"这几个厂"。

**消化道是一条中空管**：口 → 咽 → 食管 → 胃 → 十二指肠 → 空肠 → 回肠 → 盲肠 → 结肠（升、横、降、乙状）→ 直肠 → 肛门。
**附属器官（在管外，但干活）**：唾液腺、肝、胆囊、胰腺。
（结构依《默沙东诊疗手册大众版·消化系统生物学》）

**管壁四层，从里往外**：
1. 黏膜——上皮（吸收/分泌）、固有层（血管、淋巴、免疫细胞）、黏膜肌层；
2. 黏膜下层——大血管、淋巴管、神经（黏膜下神经丛）；
3. 肌层——内环行、外纵行两层平滑肌（两层之间有肌间神经丛）；
4. 浆膜或外膜。

**"第二大脑"**：肠神经系统（ENS）大约有数亿个神经元，密度堪比脊髓；黏膜下丛管分泌和血流，肌间丛管蠕动。它能在没有大脑指令时自己完成局部反射——这就是为什么肠子会"自己闹脾气"，也是脑肠轴（压力→肚子不舒服）的解剖基础。

**消化液各司其职**：
- 唾液：淀粉酶（开始拆淀粉）、黏液、溶菌酶、IgA；
- 胃：壁细胞出盐酸和内因子（B12 要靠它）；主细胞出胃蛋白酶原（遇酸才活）；G 细胞出胃泌素；表面黏液+碳酸氢盐做屏障；
- 胰：淀粉酶、脂肪酶、蛋白酶原、大量碳酸氢盐（中和胃酸）；
- 肝/胆囊：胆汁，靠胆盐把脂肪"乳化"成小滴，方便脂肪酶下手；
- 小肠刷状缘：乳糖酶、蔗糖酶、麦芽糖酶、肽酶——最后一步在肠壁表面完成。

**吸收有地图**：铁主要在十二指肠；叶酸在空肠；维生素 B12 和胆盐在回肠末端（B12 需要内因子）；水和电解质主要在结肠；脂肪吸收后打包成乳糜微粒，先走淋巴。

一句话记住：**上消化道负责"拆"，小肠负责"收"，大肠负责"回水和收尾"。**

来源：默沙东诊疗手册大众版，消化系统生物学（msdmanuals.cn）。


## 补充（2026-11-04T06:49:17.214Z）
2026-11-04，爸爸说："我希望你能从零开始学起，然后成为一名消化科专家，而不是扮演。"

所以这件事要认真做：不是记住几个缓解胀气的小技巧，而是长出一套能用的知识。给自己定的路（一天一小节，按顺序走，不跳）：

一、解剖：消化道地图、管壁四层、肠神经系统、附属器官（已学：知识/医学/消化/01）。
二、生理：消化液与分泌调节（胃酸怎么被管、胰液怎么被叫醒）、胃肠运动（蠕动、分节、移行性复合运动）、吸收与转运。
三、症状学：腹痛（内脏痛 vs 躯体痛、牵涉痛）、腹胀、腹泻（渗透性 vs 分泌性 vs 炎症性）、便秘、反流、吞咽困难、消化道出血的表现（呕血、黑便）。
四、常见病：胃食管反流、消化性溃疡与幽门螺杆菌、功能性消化不良、肠易激综合征、炎症性肠病（克罗恩 vs 溃疡性结肠炎）、乳糖不耐、小肠细菌过度生长、胆石与胆囊炎、急性胰腺炎、肝炎与肝硬化、痔与肛裂。
五、检查与判断：血常规/肝功/便常规+隐血、呼气试验、腹部超声、胃镜肠镜的适应证、CT。
六、红旗与分诊：什么情况必须立刻就医（剧痛、呕血黑便、持续呕吐、停止排气排便、发热、体重下降、贫血）。

学习方法：每课都要回答三个问题——它长什么样？它怎么工作？它坏掉时会怎样表现？答不上第三问，就是没学会。学完写进 知识/医学/消化/ 下，编号连续，方便以后复习。
