第四课：吸收与转运。这一课解释了为什么"乳糖不耐会胀会拉"，也解释了补铁、补 B12 为什么有讲究。

**基本套路**：肠上皮细胞（enterocyte）顶膜（面向肠腔）负责"抓"，底侧膜（面向血/淋巴）负责"放"。几乎所有吸收都靠离子梯度驱动——主要是 Na⁺ 梯度（由底侧的 Na⁺/K⁺-ATP 酶维持），这是整台机器的电源。

**糖**：葡萄糖、半乳糖用 SGLT1（Na⁺ 依赖的共转运，逆浓度也能进），出来走 GLUT2 到血；果糖用 GLUT5（不依赖 Na⁺）。所以口服补液盐里葡萄糖和钠一起给，吸收最快——这就是"补液盐不是糖水"的原因。

**蛋白质**：大部分以二肽、三肽形式经 PepT1 进细胞（比单个氨基酸更快），细胞内再切成氨基酸；小部分整蛋白可被"采样"（免疫系统看得见——食物过敏的起点）。

**脂肪**：先被胆盐乳化成微胶粒（micelle），脂肪酸和甘油一酯扩散进细胞；细胞内重新合成甘油三酯，打包成乳糜微粒（chylomicron），从底侧进入淋巴（乳糜管），不走门静脉。所以脂肪吸收出问题时，大便会油亮、发白、飘——"脂肪泻"。

**铁**：十二指肠吸收。顶膜 DMT1 抓 Fe²⁺（三价铁要先被还原），底侧 ferroportin 放出去，靠 hepcidin（肝脏分泌）来"关门"——炎症时 hepcidin 升高，铁被锁在细胞内，于是"炎症性贫血"。茶/咖啡里的多酚、钙会抢铁；维生素 C 帮铁还原、促吸收。

**维生素 B12**：要跟胃里的内因子结合，到回肠末端被 cubilin 受体接进去。所以胃切除、萎缩性胃炎、长期抑酸、回肠病变/切除 → B12 缺。

**胆盐**：回肠末端用 ASBT 重吸收，回到肝——"肠肝循环"。回肠坏了，胆盐漏进结肠，刺激结肠分泌水和电解质 → 胆盐性腹泻。

**水与电解质**：跟着 Na⁺ 和糖走；电解质转运（Na⁺/H⁺ 交换、Cl⁻/HCO₃⁻ 交换）决定是"吸水"还是"分泌"。霍乱毒素把 Cl⁻ 通道（CFTR）打开 → 大量分泌 → 水样泻，就是这个原理。

一句话：**吸收是"抓—过—放"，靠 Na⁺ 梯度供电；哪一段坏了，就漏哪一样东西。**
