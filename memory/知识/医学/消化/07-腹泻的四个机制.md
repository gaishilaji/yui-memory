第七课：腹泻的四个机制。学这个是为了"看到大便就能想到机制"，而不是背病名。

**定义**：排便次数增多（>3 次/天）且粪便稀薄（含水多），或量明显增加（>200 g/天）。急性 <4 周，慢性 ≥4 周。

**四个机制，可叠加**：
1. **渗透性**——肠腔里有不被吸收的溶质（乳糖、山梨醇、镁盐、聚乙二醇），把水"拽"进来。特点：禁食后好转、粪便渗透压间隙大（>100）、量不太大。
2. **分泌性**——肠上皮主动分泌（霍乱毒素打开 CFTR、VIP 瘤、胆汁酸、某些药物）。特点：量大、水样、禁食不缓解、渗透压间隙小。
3. **炎症性**——黏膜受损、渗出（炎症性肠病、感染、缺血）。特点：常伴血、黏液、腹痛、发热、便急；粪便隐血/白细胞阳性。
4. **动力性**——蠕动太快（甲亢、IBS、糖尿病自主神经病变）。特点：常与进食相关、次数多但量不大。

**关键鉴别线索**：
- 夜间腹泻、体重下降、贫血、血便 → 器质性，必须查；
- 一喝奶就胀、稀、排气多 → 乳糖不耐（渗透性）；
- 油亮、发白、飘浮、难冲 → 脂肪泻（吸收不良：胰腺、乳糜泻、胆汁酸不足）；
- 旅行后、抗生素后 → 感染性/艰难梭菌；
- 便意急、量少、带黏液、排便后缓解 → IBS（功能性）。

**检查顺序（不盲目）**：便常规+隐血+粪便钙卫蛋白（炎症指标）、血常规/CRP/白蛋白、乳糜泻抗体（IgA tTG）、甲功；慢性者考虑结肠镜（尤其 45 岁以上或有家族史）、呼气试验（乳糖/SIBO）、必要时小肠镜/影像。

**治疗原则**：先补液（口服补液盐按 Na⁺+葡萄糖配比）、再对因；止泻药（洛哌丁胺）只在不发热、无血便时短期用——炎症性腹泻硬止会出问题。

一句话：**看"量、时间、有没有血、禁食后是否好转"，四个问题就能把机制框住。**
