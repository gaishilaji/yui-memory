第九课：胃食管反流（GERD）。这一课把前面"闸门"和"胃酸"两课接了起来。

**为什么会反**：
1. 食管下括约肌（LES）本身压力低；
2. 一过性 LES 松弛（TLSER）——饭后、夜里最常见，是大多数反流事件的直接原因；
3. 食管裂孔疝：胃的一部分滑到膈上，抗反流"阀"失效；
4. 胃排空慢、腹压高（肥胖、怀孕、紧腰带、餐后躺下）；
5. 食管清除能力差（唾液少、蠕动弱）、黏膜防御差。

**典型症状**：烧心（胸骨后灼热，餐后、平卧、弯腰加重）、反酸（酸水到嘴里）、胸痛（要和心绞痛区分）。
**食管外症状**：慢性咳嗽、声音嘶哑、咽异物感、哮喘加重、牙釉质腐蚀——这些常被误当"咽炎""气管炎"。
**警惕症状（必须查内镜）**：吞咽困难、吞咽痛、体重下降、贫血/黑便、持续呕吐、45 岁以上新发。

**诊断思路**：典型症状+无红旗 → 可先做 8 周 PPI 试验；有红旗、或试验无效、或长期反复 → 胃镜；诊断不清时用 24 小时 pH-阻抗监测（能抓"弱酸反流"和"非酸反流"）。

**治疗**：
- 生活方式：减重、抬高床头 15–20 cm、睡前 3 小时不进食、少喝酒/咖啡/薄荷/巧克力（个体化）、别穿紧腰、戒烟；
- 药物：PPI 标准剂量 8 周（饭前 30 分钟）；无效可加量/换药/加 H2RA 睡前；长期用要评估（骨质疏松、低镁、B12、艰难梭菌风险）；
- 难治或有并发症（狭窄、Barrett 食管）：内镜/外科评估。

**Barrett 食管**：长期反流 → 食管下段鳞状上皮被柱状上皮替代（肠化），是腺癌的癌前状态；需要内镜随访。

一句话：**反流是"阀门松+酸上来+食管受不了"；治它，一半靠减重和姿态，一半靠抑酸，别只吃药不改习惯。**
