第十一课：肠易激综合征（IBS）。爸爸今天的胀气，最常见的"长期版本"就是这个。

**是什么**：一种功能性肠病——有症状（腹痛+排便改变），但查不出结构或生化异常。罗马 IV：过去 3 个月里，平均每周至少 1 天腹痛，且伴以下两条以上：与排便相关、排便频率改变、大便性状改变。

**分型**：IBS-C（便秘为主）、IBS-D（腹泻为主）、IBS-M（混合）、IBS-U（不定）。

**为什么痛**：不是"想出来的"，有几条实打实的机制——
1. 内脏高敏感：肠壁神经对撑、对气、对酸的反应阈值低；
2. 动力异常：餐后结肠反应过强（饭后就想跑厕所）、小肠传输改变；
3. 脑肠轴：压力、焦虑、睡眠差会通过迷走神经和 CRH 影响肠子；反过来肠子不舒服也让人焦虑——双向的；
4. 菌群与发酵：部分人小肠细菌过度生长（SIBO）、产气菌多；
5. 感染后 IBS：一次胃肠炎之后 10% 左右的人会留下这套症状；
6. 食物：不是"过敏"，更多是发酵底物（FODMAP）和组胺、咖啡因等刺激。

**怎么诊断（正向诊断，不是"排除一切"）**：典型症状+没有红旗 → 少量检查（血常规、CRP、乳糜泻抗体、便钙卫蛋白；按需甲功）即可。**红旗**：便血、体重下降、夜间症状、贫血、发热、45 岁后新发、家族史 → 必须查。

**怎么治（分层）**：
1. 解释与安心：告诉他"这不是癌、不会短命"，本身就能减轻症状；
2. 饮食：低 FODMAP 4–6 周（要在指导下，之后逐个 reintroduce）；可溶性纤维（车前子）对 IBS-C 有帮助，不溶性麦麸可能加重；
3. 药物：解痉药（匹维溴铵/薄荷油）、止泻（洛哌丁胺，按需）、通便（聚乙二醇）、低剂量三环类抗抑郁药（改善内脏高敏感，不是"治抑郁"）、利福昔明（IBS-D，部分人）、益生菌（菌株特异，证据中等）；
4. 心理与行为：认知行为治疗、肠道导向催眠——证据不比药差；
5. 运动、睡眠、减少酒精和咖啡。

一句话：**IBS 是"肠子太敏感+脑肠轴失调"，诊断靠正向标准，治疗靠分层组合，不是一辈子忌口。**
