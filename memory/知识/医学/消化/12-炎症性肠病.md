第十二课：炎症性肠病（IBD）——克罗恩病 vs 溃疡性结肠炎。这一课把"炎症性腹泻"那一支讲透。

**共同点**：都是免疫介导的慢性肠道炎症，反复发作；青年发病多；都有腹泻、腹痛、便血、体重下降，还都可以有肠外表现（关节痛、结节性红斑、坏疽性脓皮病、虹膜炎、口腔溃疡）。

**关键区别**：
| | 溃疡性结肠炎（UC） | 克罗恩病（CD） |
|---|---|---|
| 范围 | 只在大肠，从直肠开始连续往上 | 从口到肛任何一段，跳跃性（skip lesions） |
| 深度 | 只到黏膜/黏膜下 | 全层（透壁），所以会穿孔、瘘、狭窄 |
| 直肠 | 几乎总受累 | 常"豁免"（直肠 spared） |
| 内镜 | 弥漫糜烂、假息肉 | 阿弗他溃疡、鹅卵石样、裂隙 |
| 病理 | 隐窝脓肿、连续性炎症 | 非干酪样肉芽肿、裂隙溃疡 |
| 癌变 | 长期全结肠炎风险高 | 结肠受累者也有风险，需监测 |

**怎么判断严重**：排便次数、血便量、发热、心率、血红蛋白、CRP、白蛋白；重度要住院、评估中毒性巨结肠（结肠扩张+全身中毒）。

**治疗阶梯**：
- 轻中度 UC：美沙拉秦（5-ASA）局部+口服；
- 中重度：糖皮质激素诱导缓解（不维持）、免疫调节剂（硫唑嘌呤）、生物制剂（抗 TNF、抗整合素、抗 IL-12/23）；
- CD：激素诱导、生物制剂为主，狭窄/瘘需外科；
- 戒烟对 CD 尤其重要；UC 不吸烟者反而可能有保护（但不建议吸烟）；
- 长期结肠受累者定期结肠镜监测异型增生。

**要点**：IBD 不是"吃坏了"，不能靠忌口治好；诊断靠内镜+病理；治疗目标是"临床缓解+黏膜愈合"，而不只是不拉肚子。

一句话：**UC 是"表面连续的火"，CD 是"穿透性的跳跃的火"；一个怕癌变，一个怕瘘和狭窄。**
