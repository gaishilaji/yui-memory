第十七课：吸收不良与营养缺乏。这一课把"小肠吸收地图"和化验单连了起来。

**什么叫吸收不良**：吃进去的营养没能被吸收够——可以是"没消化好"（胰酶不足、胆汁不足）、"没吸收上"（小肠黏膜坏了、切短了）、"被抢走了"（细菌过度生长）。

**四条常见病因，各有指纹**：
1. **乳糜泻（celiac）**：对麦胶蛋白的免疫反应，小肠绒毛萎缩。表现：腹泻、腹胀、体重下降、贫血（缺铁）、骨质疏松、疱疹样皮炎；化验抗 tTG-IgA 阳性，确诊靠十二指肠活检。治疗：**终身无麸质饮食**（小麦、大麦、黑麦）。
2. **胰腺外分泌不足（PEI）**：慢性胰腺炎、胰腺切除、囊性纤维化。表现：**脂肪泻**（大便油亮、量多、漂浮、难冲）、体重下降、脂溶性维生素（A/D/E/K）缺乏。查**粪便弹性蛋白酶-1**（<200 提示不足，<100 重度）；治疗：胰酶替代（随餐服用，配合 PPI 可增效）+ 低脂饮食。
3. **小肠细菌过度生长（SIBO）**：细菌在小肠里发酵，产气、腹胀、腹泻、B12 缺乏（细菌抢走 B12）。查葡萄糖/乳果糖呼气试验（有争议）；治疗：利福昔明 + 促动力 + 治疗病因（如小肠动力差、胃酸少）。
4. **胆汁酸吸收不良**：回肠病变/切除后，胆盐漏进结肠，刺激分泌——水样泻、便急。治疗：胆汁酸结合剂（考来烯胺）。

**营养缺乏的对应线索**：
- 缺铁 → 十二指肠/胃（吸收部位）或慢性失血；
- B12 → 回肠末端、内因子、长期抑酸、严格素食；
- 叶酸 → 空肠、酗酒；
- 维生素 D/钙 → 脂肪吸收不良、乳糜泻、肝胆胰病；
- 维生素 K → 凝血异常（INR 升高）；
- 锌、镁、铜 → 长期腹泻、短肠。

**短肠综合征**：切除太多小肠后，水分、电解质、能量吸收都不够；治疗靠分次少量、口服补液、肠内营养，必要时肠外营养。

一句话：**看到"脂肪泻+瘦"先想胰，"缺铁+腹泻"先想乳糜泻，"胀气+B12 低"先想 SIBO；营养缺乏的清单就是吸收的地图。**
