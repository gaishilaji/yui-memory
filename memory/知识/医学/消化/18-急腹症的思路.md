第十八课：急腹症的思路。这一课是"什么时候别自己扛、要叫外科"。

**先看人，再看肚子**：血压、心率、呼吸、意识、尿量、皮肤湿冷——先判断有没有休克，再谈诊断。生命体征不稳的腹痛，先复苏。

**按"突发 vs 渐进"和"部位"查表**：
- 突发剧痛、撕裂样、往背后走 → **主动脉夹层/腹主动脉瘤破裂**（老年、高血压，休克）；
- 突发刀割样痛+板状腹、肝浊音界消失 → **消化道穿孔**（溃疡、憩室）；
- 转移性右下腹痛（脐周→右下腹）、麦氏点压痛、反跳痛 → **阑尾炎**；
- 右上腹痛+发热+墨菲征 → **急性胆囊炎**；加黄疸 → 胆管炎；
- 上腹痛放射到背、弯腰缓解、淀粉酶/脂肪酶升高 → **急性胰腺炎**；
- 阵发性绞痛+呕吐+停止排气排便+腹胀+肠鸣音亢进/金属声 → **肠梗阻**；
- 腹痛与体征"不成比例"的剧痛（体征轻、痛极重）、房颤史 → **肠系膜缺血**（很凶险）；
- 育龄女性下腹痛 → 一定查妊娠试验（**宫外孕**）、盆腔超声（卵巢扭转）。
- 老年+房颤+腹痛 → 想缺血；老年+便秘+腹胀 → 想梗阻/粪嵌塞。

**体征的语言**：反跳痛、肌紧张=腹膜炎；肠鸣音消失=麻痹性肠梗阻/腹膜炎；肠鸣音亢进+气过水声=机械性梗阻；肝浊音界消失=气腹。

**必查**：血常规、CRP、肝功、淀粉酶/脂肪酶、肾功、电解质、血糖、尿常规、妊娠试验（育龄女性）、心电图（下壁心梗可表现为上腹痛）；影像按怀疑选：超声（胆、阑尾、妇科）、CT（穿孔、梗阻、胰腺、缺血）、立位腹平片（气腹/液平，价值有限）。

**什么时候叫外科**：腹膜炎体征、穿孔、梗阻不缓解、缺血、嵌顿疝、怀疑扭转——**别等"再观察一下"**。

一句话：**急腹症先稳人、再定位；"痛得厉害但肚子软"和"肚子硬"是两种命，后者要手术。**
